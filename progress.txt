## Codebase Patterns
- Dismissible banners: useState(false) + localStorage restore in useEffect; key pattern 'omni-*-dismissed'; apply id to text div + aria-describedby on dismiss button
- Nav descriptions in AppShell: extend navItems array with description field; render below label in dimmer font; opacity-0 on inactive, always-visible on active
- Tailwind v4: no config file; utility classes only; @import "tailwindcss" in globals.css
- Info banners: border border-blue-500/20 bg-blue-500/5 rounded-lg p-4 flex items-start gap-3
- All pages guard no-workspace state with early return showing a Go to Home link
- Keyboard shortcuts in textareas: onKeyDown e.key + e.ctrlKey/e.metaKey check; always e.preventDefault() before calling handler
