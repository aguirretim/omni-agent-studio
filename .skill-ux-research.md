## UI/UX Skills Found

### accessibility-specialist (imsaif/design-with-claude)
- Source: https://github.com/imsaif/design-with-claude/blob/main/commands/accessibility-specialist.md
- Quality: production
- Content: Full WCAG 2.1 AA/AAA specialist. Covers POUR principles (Perceivable, Operable, Understandable, Robust). Encodes: color contrast ratios (4.5:1 normal, 3:1 large/UI), keyboard nav (tab order, focus indicators, skip links, escape key), focus management (modal trapping, return focus), ARIA rules (prefer native HTML, aria-label, aria-expanded, aria-live), screen reader semantics (single h1, alt text, form labels, table markup), touch targets (48x48px min). Includes a 10-point audit checklist. Engages via: describe UI → get prioritized audit with code fixes.
- Verdict: use as-is — most complete standalone accessibility command found

## Research/Peer Review Skills Found

### academic-paper-reviewer v1.4 (Imbad0202/academic-research-skills)
- Source: https://github.com/Imbad0202/academic-research-skills/blob/main/academic-paper-reviewer/SKILL.md
- Quality: production
- Content: 7-agent peer review system simulating a complete journal peer review process. Team: Editor-in-Chief (journal fit, originality), Methodology Reviewer (research design, statistics), Domain Reviewer (literature, theory), Perspective Reviewer (cross-disciplinary), Devil's Advocate (logical fallacies, counter-arguments — CRITICAL findings block acceptance), Field Analyst (configures reviewers), Editorial Synthesizer (consolidates). Five modes: full / re-review / quick (15-min EIC assessment) / methodology-focus / guided (Socratic dialogue). Three phases: field analysis → parallel multi-perspective review → editorial synthesis. Output: structured report, editorial decision letter (Accept/Minor/Major/Reject), revision roadmap. Devil's Advocate CRITICAL findings are blocking.
- Verdict: use as-is — most complete peer review skill found; production-grade with rigorous multi-agent methodology

## Recommended Skills to Build

Skills where no satisfactory community option exists, or where synthesis is needed:

1. **ux-heuristic-review** — Standalone heuristic evaluation against Nielsen's 10 Usability Heuristics. Scores each heuristic 1-4, identifies violations by severity (critical/major/minor), outputs prioritized recommendations. Basis: Nielsen's 10 heuristics + Severity Rating scale. SOURCE: Synthesize from Owl-Listener /prototyping-testing:evaluate (which exists but is buried in a large plugin; a standalone command increases discoverability)

2. **wcag-audit** — Comprehensive WCAG 2.1 AA audit command covering all four POUR principles with criterion-level references. Produces a machine-readable checklist (pass/fail/needs-manual-check per criterion) plus a human-readable prioritized report. Basis: WCAG 2.1 AA success criteria 1.1.1–4.1.3. SOURCE: Synthesize combining imsaif accessibility-specialist + accesslint:reviewer methodology

3. **design-critique** — Structured design critique following a 5-dimension framework: Visual Hierarchy, Interaction Quality, Consistency, Accessibility, Emotional Resonance. Provides specific, actionable critique tied to design principles rather than personal preference. Basis: Design critique best practices + Norman's principles. SOURCE: Synthesize from imsaif/design-with-claude specialist pool

4. **peer-review** — Academic peer review of documents/research papers using the simulated-referee approach. Adapted from Imbad0202 academic-paper-reviewer for non-journal contexts (internal reports, technical docs, policy papers). Modes: quick-review (5-min summary), full-review (multi-reviewer), methodology-check. SOURCE: Adapt from Imbad0202/academic-research-skills/academic-paper-reviewer

5. **literature-review** — Systematic literature review command for non-biomedical domains (tech, design, business). Follows PRISMA-inspired workflow but scopes to Google Scholar, Semantic Scholar, arXiv. Produces annotated bibliography + synthesis narrative + evidence table. Basis: PRISMA 2020 + Campbell Collaboration systematic review guidelines. SOURCE: Adapt from Imbad0202 deep-research lit-review mode + fastmcp literature-review skill

6. **research-synthesis** — Takes a collection of sources/documents and produces a structured synthesis: key themes, agreements, contradictions, evidence gaps, and recommended further research. No database searching required (user provides sources). Basis: Systematic review synthesis methodology. SOURCE: Synthesize; gap not covered by any found skill

## Key Standards to Encode

### UX
- **Nielsen's 10 Usability Heuristics**: Visibility of system status, Match between system and real world, User control and freedom, Consistency and standards, Error prevention, Recognition rather than recall, Flexibility and efficiency of use, Aesthetic and minimalist design, Help users recognize/diagnose/recover from errors, Help and documentation
- **Severity Rating Scale** (Nielsen): 0 (not a problem) → 4 (usability catastrophe)
- **Norman's Design Principles**: Affordance, Signifiers, Constraints, Mappings, Feedback, Conceptual model
- **POUR Framework**: Perceivable, Operable, Understandable, Robust (from WCAG)
- **Evidence-based feedback**: Problems over prescriptions; describe impact not solutions

### Accessibility
- **WCAG 2.1 AA**: Primary target — 50 success criteria across Levels A and AA
- **Key criteria**: 1.1.1 Non-text Content, 1.3.1 Info and Relationships, 1.4.3 Contrast (Minimum) 4.5:1 / 3:1, 1.4.11 Non-text Contrast 3:1, 2.1.1 Keyboard, 2.4.3 Focus Order, 2.4.7 Focus Visible, 4.1.2 Name Role Value, 4.1.3 Status Messages
- **Testing tools to reference**: axe-core (automated), NVDA/VoiceOver (screen readers), keyboard-only navigation, color blindness simulators
- **Touch targets**: 48x48px minimum (WCAG 2.5.5 AAA, but 44x44 is iOS HIG standard)
- **ARIA authoring practices**: WAI-ARIA Authoring Practices Guide 1.2

### Research / Peer Review
- **Peer review conventions**: Double-blind preferred; Editor + 2-3 independent reviewers; structured rubric (originality, methodology, evidence, clarity, significance); Accept / Minor Revision / Major Revision / Reject decision; revision response tracking
- **Literature review methodology**: PRISMA 2020 for systematic reviews; PICO framework for question framing; minimum source thresholds (15+ for narrative, 25+ for systematic); ≥2 databases with documented search strings; risk-of-bias assessment (RoB 2, ROBINS-I); GRADE certainty of evidence
- **Citation standards**: DOI verification required; APA 7.0 default; support for Nature, Vancouver, Chicago, IEEE
- **Quality assessment tools**: Cochrane RoB 2 (RCTs), ROBINS-I (non-randomized), Newcastle-Ottawa Scale (observational), AMSTAR 2 (systematic reviews)
- **Research integrity**: EQUATOR reporting guidelines; claim-citation linkage (every claim must cite); explicit limitations section
